# 進階語言功能

寫了十幾章 Rust，`println!` 後面的 `!` 一直是個謎，編譯器不肯放行的地方也只能乖乖照辦。這一章把藏在背後的東西一次攤開：巨集怎麼在編譯時期替你寫程式、`unsafe` 到底多給你什麼、怎麼跟 C 打交道、怎麼讓編譯器在編譯時期就算好東西，以及怎麼依條件、依檔案決定要編譯什麼。

這些功能多數是「寫別人用的程式庫」或「碰到特殊情況」才用得上，日常的應用程式不太會天天寫。但你每天都在用它們的成果：`println!`、`#[derive(Debug)]`、`#[tokio::main]`、`#[cfg(test)]` 全都在這一章。最後再補上一集 `TryFrom`，給你一個不會悄悄截斷的轉換方式。
