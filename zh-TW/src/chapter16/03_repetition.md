# 重複 `$(...)*`

## 本集目標

會在 `macro_rules!` 裡用 `$(...)*`、`$(...)+`、`$(...)?` 處理「重複好幾次」的引數，也會寫遞迴的巨集，以及把引數原封不動轉交給 `format!` 這類巨集。

## 正文

### 重複的寫法

上一集的巨集引數個數都是寫死的。`vec![1, 2, 3]` 想收任意個引數，靠的是重複：

```text
$( 要重複的樣子 ) 分隔符 重複符
```

- 重複符有三種：`*` 是零次以上，`+` 是一次以上，`?` 是零次或一次。
- 分隔符是選用的，常見的是 `,` 或 `;`；`?` 不能放分隔符，否則是編譯錯誤。
- 比對的那一邊與展開的那一邊都用 `$( ... )`。比對時，每重複一次就抓到一組；展開時，裡面的內容會依抓到的組數重複寫出來。

### 例子：一次放進好幾組價格

飲料店的菜單是一堆「名稱 => 價格」，我們寫個巨集，把它們收進 `HashMap`：

```rust
use std::collections::HashMap;

macro_rules! prices {
    ($($name:expr => $price:expr),* $(,)?) => {{
        let mut map = HashMap::new();
        $(map.insert($name, $price);)*
        map
    }};
}

fn main() {
    let menu = prices!(
        "紅茶" => 30,
        "咖啡" => 45,
        "奶茶" => 38,
    );
    println!("{}", menu.len());
    println!("{:?}", menu.get("咖啡"));
}
```

執行結果：

```text
3
Some(45)
```

- 比對的那一邊：`$($name:expr => $price:expr),*` 讀作「一組 `名稱 => 價格`，用逗號隔開，重複零次以上」。`=>` 只是我們自己選的分隔字樣，巨集比對的是程式碼的一個個 token，所以可以放進任何合法的 token。
- 展開的那一邊：`$(map.insert($name, $price);)*` 對每一組都寫一行 `map.insert(...)`，三組就是三行。
- `$name` 與 `$price` 在同一個重複裡一起走，所以每次拿到的是同一組的名稱與價格。兩個變數抓到的次數不一樣，編譯器會說 ``meta-variable `a` repeats 3 times, but `b` repeats 2 times``。
- 最後的 `$(,)?` 允許結尾多寫一個逗號。少了它，`"奶茶" => 38,` 後面的逗號會讓比對失敗：`unexpected end of macro invocation`，因為逗號後面它還等著下一組。多行呼叫時習慣在最後一行也加逗號，這類巨集幾乎都會寫這一行。
- `expr` 後面只能接 `=>`、`,`、`;` 其中之一，所以才用 `=>` 隔開名稱和價格；換成 `-` 之類的字樣，巨集定義本身就編譯不過。

`HashMap` 的走訪順序不固定，所以範例只印筆數與查到的價格。

### `+` 與遞迴

重複符 `+` 要求至少一次。常見的搭配是遞迴：巨集的展開結果裡再呼叫自己，每次少處理一個引數：

```rust
macro_rules! total {
    ($x:expr) => {
        $x
    };
    ($x:expr, $($rest:expr),+) => {
        $x + total!($($rest),+)
    };
}

fn main() {
    println!("{}", total!(30));
    println!("{}", total!(30, 45, 38));
}
```

執行結果：

```text
30
113
```

`total!(30, 45, 38)` 先展開成 `30 + total!(45, 38)`，再展開成 `30 + 45 + total!(38)`，最後是 `30 + 45 + 38`。第一條規則是遞迴的終點，只剩一個引數；第二條規則把第一個引數取出來，其餘的用 `$($rest),+` 再交給自己。遞迴有上限（預設 128 層），超過是 ``recursion limit reached while expanding `名字!` ``。

### 把引數原封不動轉交出去

很多巨集只是替別的巨集加一點料，例如替 `println!` 加上固定的字首。這時不需要看懂引數長什麼樣，用 `tt`（任何一個 token tree）加 `*`，整串抓起來再原樣交出去：

```rust
macro_rules! say {
    ($($arg:tt)*) => {
        println!("[店員] {}", format!($($arg)*))
    };
}

fn main() {
    let name = "紅茶";
    say!("{name} 賣 {} 元", 30);
    say!("歡迎光臨");
}
```

執行結果：

```text
[店員] 紅茶 賣 30 元
[店員] 歡迎光臨
```

`$($arg:tt)*` 把 `"{name} 賣 {} 元", 30` 拆成一個個 token，展開時 `format!($($arg)*)` 再依序放回去，所以 `format!` 看到的跟你直接寫給它的一模一樣，格式字串的編譯時期檢查照樣有效，`{name}` 也照樣讀得到呼叫端的變數。第 17 章第 10 集 `tracing` 的 `info!` 這類記錄巨集，用起來也是「格式字串加引數」，寫法跟 `println!` 一樣。

寫巨集最常遇到的訊息，是 ``variable `x` is still repeating at this depth``：`$x` 是在重複裡面抓到的，展開時卻寫在 `$( ... )` 的外面。凡是在重複裡抓到的變數，都只能在對應的重複裡使用。

## 重點整理

- `$( 樣子 ) 分隔符 重複符`：`*` 零次以上、`+` 一次以上、`?` 零次或一次；比對與展開兩邊都這樣寫，展開時依抓到的組數重複。
- 同一個重複裡的變數一起走；抓到的次數不一致、或在重複外面使用，都是沒有錯誤碼的編譯錯誤。
- `$(,)?` 讓呼叫端可以在最後多寫一個逗號；`expr` 後面只能接 `=>`、`,`、`;`。
- 遞迴巨集：第一條規則放終點，第二條取出第一個引數、其餘再交給自己；預設遞迴上限 128 層。
- `$($arg:tt)*` 可以把整串引數原樣轉交給 `println!`、`format!` 等巨集。
