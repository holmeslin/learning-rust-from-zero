# enum 與模式比對

訂單是「等待付款、已付款、已出貨」其中一種，折扣可能是「打折、折抵金額、滿額折」其中一種。這類「只會是其中一種、而且每種帶的資料還不一樣」的東西，用 struct 很難表達。這一章用 `enum` 定義它們，再用 `match` 針對每一種各寫一個處理分支。

Rust 的 `match` 有一個你在 Go 的 `switch` 看不到的特點：漏掉任何一種可能，程式就編譯不過。Go 的 `nil` 在這一章也會消失，換成 `Option<T>`：「可能沒有值」寫在型別上，不處理就不能用。後半章再補上 `if let`、`let else`、解構、`matches!` 這些處理模式的小工具，最後讓 enum 也能用 `impl` 加方法。
