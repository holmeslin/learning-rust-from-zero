# 實戰：CLI 工具

這一章開始進入實戰：把前面學過的東西組起來，寫成一支真正有人會用的命令列工具，飲料店的 `teashop`。從最原始的 `std::env::args` 讀引數開始，接著換成 `clap`，由它解析引數與子命令，再補上命令列工具該有的規矩：用結束碼告訴呼叫者成敗、接上 stdin 與 stdout 的管線、走訪整個資料夾、收到 Ctrl-C 時好好收工。

每一集都是一個能用 `cargo run` 跑起來的專案，書上貼的指令與輸出都是實際執行過的。最後一集把零件組在一起，並用 `cargo test` 把行為守住。這一章會用到第 15 章的 tokio 與第 17 章的 `thiserror`，也是 `clap` 第一次出場。
