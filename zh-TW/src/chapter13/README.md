# 智慧指標

前面的章節，值不是由變數擁有，就是用參照借來用。這一章介紹第三種：智慧指標（smart pointer）。它像指標一樣指向別處的資料，卻多了幾種本事：擁有那份資料、計算有幾個擁有者、離開時自動收拾。`Box` 把值放進 heap，`Deref` 與 `Drop` 讓自己的型別也能這樣運作；`Rc`、`RefCell`、`Weak`、`Cell` 解決「一份資料有好幾個擁有者」和「只拿到 `&` 卻要修改資料」；最後的 `Cow` 讓「借用或擁有」可以等到執行時期才決定。

Go 的 GC 替你管這些事，Rust 沒有 GC，所以這一章的每個工具，都是在自己決定資料怎麼共用、什麼時候釋放。前面幾章先照抄的 `Box<dyn Trait>`、`&String` 自動變成 `&str`，原理也都在這裡解釋清楚。
