# 陳述式 vs 運算式

## 本集目標

分清楚陳述式（statement）和運算式（expression），明白為什麼一個分號就能讓值消失。

## 正文

### 兩個名詞

- **運算式**會算出一個值。
- **陳述式**只是做一件事，不產生值。

寫在一起比較容易看：

| 寫法 | 種類 |
| --- | --- |
| `5`、`a + b` | 運算式 |
| `add(3, 4)` | 運算式（函式呼叫） |
| `if a > b { a } else { b }` | 運算式 |
| `let x = 5;` | 陳述式 |
| `a + b;` | 陳述式（後面加了分號） |

運算式後面加上分號，就變成陳述式，它算出來的值會被丟掉。這就是上一集那個錯誤的原因：`a + b;` 是陳述式，函式的最後一行沒有值可以交出去。

### 區塊也是運算式

大括號圍起來的一段程式叫**區塊**。區塊裡可以有很多陳述式，最後一個沒有分號的運算式，就是整個區塊的值：

```rust
fn main() {
    let y = {
        let base = 10;
        base * 2 + 1
    };
    println!("{y}");
}
```

執行結果：

```text
21
```

區塊裡的 `let base = 10;` 是陳述式，只是做事；最後的 `base * 2 + 1` 沒有分號，是區塊的值，被放進 `y`。`base` 只存在於這個區塊裡，區塊外面看不到。

函式的大括號本身就是區塊，所以「最後一個運算式是回傳值」跟這裡是同一件事，不是函式才有的特例。第 1 章第 8 集的 `if` 也是：每個分支的大括號都是區塊，所以能當值用。

### 分號讓值消失

把剛才區塊的最後一行加上分號，區塊就沒有值了：

```rust,compile_fail=E0308
fn main() {
    let y: i32 = {
        let base = 10;
        base * 2 + 1;
    };
    println!("{y}");
}
```

編譯錯誤：

```text
error[E0308]: mismatched types
 --> src/main.rs:2:18
  |
2 |       let y: i32 = {
  |  __________________^
3 | |         let base = 10;
4 | |         base * 2 + 1;
  | |                     - help: remove this semicolon to return this value
5 | |     };
  | |_____^ expected `i32`, found `()`
```

錯誤訊息跟上一集很像：區塊「想」交出 `i32`，結果最後是陳述式，什麼都沒有（`()`）。記法只有一條：**想當成值的那一行，結尾不加分號；只是要做事的那一行，結尾加分號。**

## 重點整理

- 運算式算出一個值；陳述式只做事、不產生值。
- `let ...;` 是陳述式；`5`、`a + b`、函式呼叫、`if` 都是運算式。
- 大括號區塊也是運算式，值是最後一個沒有分號的運算式。
- 運算式後面加分號，就變成陳述式，值會被丟掉。
- 函式回傳值與 `if` 當值用，都是這個規則的應用。
