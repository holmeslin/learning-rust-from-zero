# 借用與切片

上一章最後留下一個麻煩：函式只想讀一下，卻得把所有權拿走、再還回來。這一章用**借用**解決它：把參照（`&`）借給函式，用完還你，所有權不用搬家。我們從 `&` 與 `&mut` 開始，學借用的規則、參照能活多久、為什麼懸置參照在 Rust 裡寫不出來，最後看字串與陣列的 slice，它們是借用最常見的樣子。

借用規則是 Go 裡沒有的東西：Go 的指標想指幾個、想寫都行，Rust 在編譯時期就管著。這一章會遇到不少借用錯誤（E0499、E0502、E0106……），每個錯誤都對應一條規則，讀懂訊息就知道要怎麼改。讀完這一章，第 3 章為了交還所有權而寫的 tuple 和 `let msg = f(msg);`，大多可以收起來了。
