# 參照 `&`

## 本集目標

用 `&` 建立參照，知道參照指向別人擁有的值、自己不擁有它，型別寫成 `&String`。

## 正文

### 建立參照

在變數前面加 `&`，就得到這個變數的**參照**（reference）：

```rust
fn main() {
    let s = String::from("哈囉");
    let r = &s;
    println!("{s}");
    println!("{r}");
}
```

執行結果：

```text
哈囉
哈囉
```

`r` 是 `s` 的參照。`let r = &s;` 沒有 move，所以 `s` 照樣能用；`println!` 印 `r` 時，印出來的是它指向的那個 `String`。

參照只是「指向」另一個值，自己不擁有任何東西。記憶體裡的樣子是：

```text
r                 s                            heap
[ 指向 s ] ---> [ ptr | len 6 | cap 6 ] ---> 哈囉
```

`String` 的擁有者始終是 `s`。`r` 本身很小，只記著 `s` 在哪裡。

### 參照的型別

`&s` 的型別是 `&String`，讀成「指向 `String` 的參照」。型別標註寫起來是這樣：

```rust
fn main() {
    let s = String::from("哈囉");
    let r: &String = &s;
    println!("{}", r.len());
}
```

執行結果：

```text
6
```

`r.len()` 跟 `s.len()` 的寫法一樣。為什麼對參照也能這樣呼叫，第 5 章第 10 集會解釋，現在照寫就好。

### 參照不擁有，所以可以複製

`let t = s;` 會把 `String` move 給 `t`（第 3 章）。但參照不擁有資料，複製它只是多一個「指向 `s`」的值，沒有任何所有權搬家：

```rust
fn main() {
    let s = String::from("哈囉");
    let r1 = &s;
    let r2 = r1;
    println!("{s} {r1} {r2}");
}
```

執行結果：

```text
哈囉 哈囉 哈囉
```

`s`、`r1`、`r2` 三個都能用，記憶體裡始終只有一份 `String`。

### 這叫借用

建立參照的動作叫**借用**（borrowing）：`r` 向 `s` 借來看一看，`String` 還是 `s` 的。第 3 章的錯誤訊息裡出現過 `borrow of moved value`，現在你知道 borrow 是什麼了。

借來的東西有規則要守，接下來幾集會逐條看。這一集先記得：`&` 建立參照，參照不擁有。

### 跟 Go 比一比

Go 的 `&s` 取得指標，看起來很像，但直覺不能照搬：

```go
s := "哈囉"
p := &s
*p = "再見" // 用指標直接改
var q *string // nil，沒指向任何東西
fmt.Println(s, q == nil) // 再見 true
```

Go 的指標能讀也能寫，可以是 `nil`，想存多久都行，反正有垃圾回收兜底。Rust 的 `&s` 預設只能讀，而且一定指向一個真的存在的值。要寫、要存多久，都有規則管，後面幾集會看到。

## 重點整理

- `&s` 建立 `s` 的參照，型別是 `&String`；建立參照不會 move，`s` 照樣能用。
- 參照指向別人擁有的值，自己不擁有，所以參照可以複製，不會有所有權搬家。
- 建立參照的動作叫借用（borrowing）；第 3 章錯誤訊息裡的 `borrow` 就是這個意思。
- 參照預設只能讀，一定指向有效的值；Go 的指標可以寫、可以是 `nil`。
