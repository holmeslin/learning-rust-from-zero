# 集合

今天賣了幾杯飲料、使用者輸入了幾個名字、每種品項各點了幾杯：這些資料在寫程式的時候，筆數是不知道的。陣列的長度寫死在型別裡，裝不了這些東西。這一章學標準函式庫裡幾種長度可以變動的集合：`Vec` 放一排值，`String` 放文字，`HashMap` 把鍵對應到值，`HashSet` 存不重複的值，`BTreeMap` 則是依鍵排好序的 map。

這些型別都擁有它們的資料，前面幾章學的所有權與借用，在這裡會天天遇到：手上還有元素的參照，就不能 `push`；字串不能用索引；`HashMap` 的 `get` 回傳 `Option`。Go 的 slice、string、map 用起來很順手，Rust 的版本多了幾道檢查，這章會逐項點出來。
