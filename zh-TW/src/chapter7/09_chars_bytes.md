# `chars` 與 `bytes`

## 本集目標

用 `s.chars()` 逐字元走訪字串、用 `s.bytes()` 逐位元組走訪，並用它數出字元數。

## 正文

### `chars()`：逐字元

`s.chars()` 的結果可以直接放在 `for` 後面走訪，每一圈拿到一個 `char`（第 1 章第 18 集）。`for` 為什麼能走訪它，第 11 章會解釋，現在跟 `for x in &v` 一樣照寫：

```rust
fn main() {
    let s = String::from("紅茶 tea");
    for c in s.chars() {
        println!("{c:?}");
    }
}
```

執行結果：

```text
'紅'
'茶'
' '
't'
'e'
'a'
```

`{c:?}` 會把 `char` 用單引號印出來，連空格也看得出來。「紅」「茶」各是一個字元，雖然各佔 3 個位元組。`char` 有自己的方法，例如 `len_utf8()` 回傳這個字元在 UTF-8 裡佔幾個位元組：

```rust
fn main() {
    let s = String::from("紅茶 tea");
    let mut count = 0;
    for c in s.chars() {
        println!("{c:?} 佔 {} 個位元組", c.len_utf8());
        count += 1;
    }
    println!("{count} 個字元，{} 個位元組", s.len());
}
```

執行結果：

```text
'紅' 佔 3 個位元組
'茶' 佔 3 個位元組
' ' 佔 1 個位元組
't' 佔 1 個位元組
'e' 佔 1 個位元組
'a' 佔 1 個位元組
6 個字元，10 個位元組
```

### 數字元

第 2 章第 15 集留的問題在這裡解決：字元數要自己走一遍數出來，上面的 `count` 就是。`s.len()` 是位元組數，兩個數字不一樣。

`s.chars().count()` 可以一行做完，但 `count` 是迭代器的方法，第 11 章第 12 集才教；現在先用迴圈數。取第 n 個字元的 `nth`，也留到第 11 章。

### `bytes()`：逐位元組

`s.bytes()` 一樣放在 `for` 後面，每一圈拿到一個位元組，型別是 `u8`：

```rust
fn main() {
    let s = String::from("紅茶");
    for b in s.bytes() {
        println!("{b}");
    }
}
```

執行結果：

```text
231
180
133
232
140
182
```

六個位元組，前三個是「紅」，後三個是「茶」。處理二進位資料、或確定內容只有 ASCII（英文、數字）時，才會直接用位元組。

### 該用哪一個

- 處理文字內容（逐字檢查、數有幾個字）：用 `chars()`。
- 處理位元組本身（編碼、傳輸的長度）：用 `bytes()` 或 `len()`。

`chars()` 的單位是 Unicode 的字元（`char`），不一定等於畫面上看到的一個符號：有些符號由好幾個 `char` 組成。這個問題在這本書不展開。

## 重點整理

- `for c in s.chars()` 逐字元走訪，`c` 是 `char`；`for b in s.bytes()` 逐位元組走訪，`b` 是 `u8`。
- 字元數要自己數：用迴圈累加；`s.len()` 是位元組數，中文字佔 3 個，兩者不同。
- `c.len_utf8()` 回傳一個 `char` 佔幾個位元組。
- `s.chars().count()` 和 `nth` 是迭代器的方法，第 11 章才教；`for` 能走訪 `chars()` 的原理也在第 11 章。
