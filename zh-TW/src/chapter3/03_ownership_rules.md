# 所有權三條規則

## 本集目標

記住所有權的三條規則，並在程式裡認出誰是擁有者、它的作用域到哪裡結束。

## 正文

### 三條規則

1. 每一個值，都有一個變數是它的**擁有者**（owner）。
2. 同一時間，一個值只會有**一個**擁有者。
3. 擁有者離開**作用域**（scope）時，這個值就會被丟棄（drop），記憶體跟著釋放。

整章都在講這三條。先看一個最小的例子：

```rust
fn main() {
    let s = String::from("哈囉");
    println!("{s}");
}
```

執行結果：

```text
哈囉
```

`String::from("哈囉")` 做出一個 `String` 值，`let s =` 讓 `s` 成為它的擁有者（規則 1）。這個值現在只有 `s` 一個擁有者（規則 2）。`main` 的 `}` 一到，`s` 離開作用域，值就被丟棄（規則 3）。

### 作用域

**作用域**指的是變數可以用的範圍：從它用 `let` 建立的那一行開始，到它所在的大括號 `}` 結束。大括號圍起來的叫**區塊**（第 1 章第 6 集、第 2 章第 5 集看過），每個區塊都有自己的作用域。

```rust
fn main() {
    let outer = String::from("外層");
    {
        let inner = String::from("內層");
        println!("{outer} {inner}");
    }
    println!("{outer}");
}
```

執行結果：

```text
外層 內層
外層
```

`inner` 的作用域到內層的 `}` 為止，所以它擁有的 `String` 在那裡就被丟棄；`outer` 要一直撐到 `main` 的 `}`。

### 三條規則各管什麼

規則 1 和規則 3 合起來，就是第 1 集看到的「沒寫 `free`，記憶體還是會還」：有擁有者，擁有者一離開，值就被丟棄。

規則 2 才是常讓人編譯不過的那條。如果兩個變數同時擁有同一份資料，它們各自離開作用域時，就會把同一塊記憶體還兩次。Rust 不讓這件事發生：把值交給別的變數時，原本的擁有者就不再算數。這叫 move，第 5 集會看到。

整數這類放在 stack 的值，也有擁有者和作用域；只是它們沒有 heap 上的資料要還，所以規則 2 對它們幾乎沒影響，第 8 集會說明。

## 重點整理

- 規則 1：每個值都有一個變數是它的擁有者。
- 規則 2：同一時間，一個值只有一個擁有者。
- 規則 3：擁有者離開作用域，值就被丟棄，記憶體釋放。
- 作用域是變數可以用的範圍，從 `let` 那一行到所在區塊的 `}`。
- 規則 2 是之後編譯錯誤的主要來源：值交給別人之後，原本的擁有者不能再用。
