# 變數與 `{}` 佔位符

## 本集目標

用 `let` 建立變數，並用 `println!` 的 `{}` 把變數印出來。

## 正文

### 用 `let` 建立變數

Go 用 `:=` 或 `var` 建立變數，Rust 一律用 `let`：

```rust
fn main() {
    let name = "小明";
    let age = 30;
    println!("{name} 今年 {age} 歲");
}
```

執行結果：

```text
小明 今年 30 歲
```

`let 名稱 = 值;` 就是建立變數。型別不用寫，編譯器會從值推斷出來，跟 Go 的 `:=` 一樣。

### `{}` 佔位符

`println!` 的第一個參數是一段文字，文字裡面的 `{}` 會被換成變數的值。大括號裡寫變數名稱，就是印出那個變數：`{name}`、`{age}`。

`{}` 裡面只能放變數名稱，不能放運算式。要印運算式的結果，就把大括號留空，把運算式寫在後面：

```rust
fn main() {
    let apple = 30;
    let banana = 25;
    println!("蘋果 {apple} 元，香蕉 {banana} 元");
    println!("總共 {} 元", apple + banana);
}
```

執行結果：

```text
蘋果 30 元，香蕉 25 元
總共 55 元
```

有幾個 `{}` 就要接幾個參數，依序填進去。`println!` 不像 Go 的 `fmt.Println` 會自動在參數之間補空格，空格要自己寫在文字裡。

要印出大括號本身，連寫兩個：`{{` 和 `}}`。

```rust
fn main() {
    println!("用 {{}} 當佔位符");
}
```

執行結果：

```text
用 {} 當佔位符
```

### 要不要標型別

型別通常不用寫。想寫出來的時候，放在名稱後面，用冒號隔開：

```rust
fn main() {
    let age: i32 = 30;
    println!("{age}");
}
```

執行結果：

```text
30
```

整數預設就是 `i32`，所以這裡寫不寫都一樣。`i32` 是 32 位元的整數，另外還有 `i64`、`u8` 等其他整數型別，第 15 集會統一介紹。現在先知道「`: 型別` 是這樣寫」就夠了，之後有些地方一定要標型別。

### 命名慣例

Rust 的變數名稱用 `snake_case`：小寫字母加底線，例如 `apple_count`，不是 Go 慣用的 `appleCount`。寫成 `appleCount` 也能編譯，但編譯器會發出警告，叫你改成 `snake_case`。

## 重點整理

- 用 `let 名稱 = 值;` 建立變數，型別由編譯器推斷。
- 想標型別就寫 `let 名稱: 型別 = 值;`，整數預設是 `i32`。
- `println!` 的 `{名稱}` 印出變數；運算式要寫成 `{}`，再把運算式放在後面當參數。
- 要印出大括號本身，寫 `{{` 和 `}}`。
- 變數名稱用 `snake_case`。
