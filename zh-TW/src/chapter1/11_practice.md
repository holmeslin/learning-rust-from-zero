# 綜合練習

## 本集目標

把前面學的變數、運算子、`if`、讀輸入和文字轉數字組合起來，從頭寫兩支完整的小程式。

## 正文

目前我們還沒學迴圈，不過光是 `if` 加上輸入，就能寫出有用的程式。每題都建議先自己寫，再看參考答案。

### 題目一：閏年判斷

寫一支程式：

1. 請使用者輸入西元年份（整數）。
2. 判斷是不是閏年：能被 4 整除而且不能被 100 整除，或者能被 400 整除。
3. 印出「2024 年是閏年」或「2023 年不是閏年」這樣的結果。

參考答案：

```rust,stdin=2024,noplayground
fn main() {
    println!("請輸入西元年份：");
    let mut line = String::new();
    std::io::stdin().read_line(&mut line).expect("讀取失敗");
    let line = line.trim();
    let year: i32 = line.parse().expect("請輸入整數");

    let is_leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
    let message = if is_leap { "是閏年" } else { "不是閏年" };
    println!("{year} 年{message}");
}
```

輸入 `2024` 的執行結果：

```text
請輸入西元年份：
2024 年是閏年
```

這支程式用到了：讀一行、`parse`、取餘數 `%`、比較與邏輯運算子，以及把 `if` 當成值。`is_leap` 和 `message` 都不用 `mut`，因為它們建立之後就不會再改。

### 題目二：兩個整數的四則運算

寫一支程式：

1. 請使用者輸入兩個整數，一個一行。
2. 印出它們的和、差、積、商（整數相除）和餘數。

參考答案：

```rust,stdin=17\n5,noplayground
fn main() {
    println!("請輸入第一個整數：");
    let mut line = String::new();
    std::io::stdin().read_line(&mut line).expect("讀取失敗");
    let line = line.trim();
    let a: i32 = line.parse().expect("請輸入整數");

    println!("請輸入第二個整數：");
    let mut line = String::new();
    std::io::stdin().read_line(&mut line).expect("讀取失敗");
    let line = line.trim();
    let b: i32 = line.parse().expect("請輸入整數");

    println!("{a} + {b} = {}", a + b);
    println!("{a} - {b} = {}", a - b);
    println!("{a} * {b} = {}", a * b);
    println!("{a} / {b} = {}", a / b);
    println!("{a} % {b} = {}", a % b);
}
```

輸入 `17` 和 `5` 的執行結果：

```text
請輸入第一個整數：
請輸入第二個整數：
17 + 5 = 22
17 - 5 = 12
17 * 5 = 85
17 / 5 = 3
17 % 5 = 2
```

這裡兩次都用同一個名字 `line`，每次都是新的變數，靠的就是第 6 集的 shadowing。

### 想一想

- 閏年的判斷，為什麼 `year % 400 == 0` 要跟前面的條件用 `||` 接起來？2000 年能被 100 整除，但還是閏年，因為它能被 400 整除；1900 年不行，所以不是閏年。
- 題目二，如果第二個整數輸入 `0` 會怎樣？整數除以 0，Rust 會 panic，訊息是 `attempt to divide by zero`，結束碼同樣是 101。

### 自己試試看

- 題目一用 `2000`、`1900`、`2023`、`2024` 各跑一次，確認四種情況都對。
- 題目二用負數試試看，例如 `-17` 和 `5`，對照第 7 集 `/` 與 `%` 的規則。
- 寫一支程式：輸入分數，依 90 分以上、60 分以上、不到 60 分，印出「優秀」「及格」「不及格」。

## 重點整理

- 寫程式前先把題目拆成步驟：讀輸入、轉成數字、計算、判斷、輸出。
- 每讀一行輸入，就重複寫一次固定句型的三行；轉數字再多寫一行。
- 不需要再改值的變數不用 `mut`；要依條件決定一個值，可以用 `if` 運算式。
- 測試時要特別試邊界值，像閏年的 1900 和 2000。
