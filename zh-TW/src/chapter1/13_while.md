# `while`

## 本集目標

用 `while` 寫「條件成立就繼續重複」的迴圈。

## 正文

### `while 條件 { ... }`

`while` 每一圈開始前先檢查條件，成立才執行，不成立就結束整個迴圈。條件跟 `if` 一樣不加小括號，而且必須是 `bool`：

```rust
fn main() {
    let mut n = 3;
    while n > 0 {
        println!("倒數 {n}");
        n -= 1;
    }
    println!("發射！");
}
```

執行結果：

```text
倒數 3
倒數 2
倒數 1
發射！
```

條件一開始就不成立的話，迴圈一次都不會執行。

### 範例：加總各位數字

重複「取個位數、再去掉個位數」，直到數字變成 0：

```rust
fn main() {
    let mut n = 12345;
    let mut sum = 0;
    while n > 0 {
        sum += n % 10;
        n /= 10;
    }
    println!("各位數字的和是 {sum}");
}
```

執行結果：

```text
各位數字的和是 15
```

`n % 10` 取出個位數，`n /= 10` 利用整數除法把個位數丟掉。這裡正好用上第 7 集學的整數除法與 `%`。

### 什麼時候用 `loop`，什麼時候用 `while`

- 知道「什麼條件下繼續」，用 `while`。
- 要在迴圈中間判斷是否結束，或是需要 `break` 帶值，用 `loop`。
- 迴圈次數固定、或是要走訪一個範圍，下一集的 `for` 更方便。

### 跟 Go 比一比

Go 只有一個 `for` 關鍵字，`for n > 0 { ... }` 就是 Rust 的 `while n > 0 { ... }`。Rust 把迴圈分成 `loop`、`while`、`for` 三種。

要注意的是，只有 `loop` 能讓 `break` 帶值；`while` 的 `break` 不能帶值，寫了會得到編譯錯誤。

## 重點整理

- `while 條件 { ... }`：條件成立就重複，條件不加小括號，必須是 `bool`。
- 條件一開始就不成立，迴圈一次都不會執行。
- Rust 有 `loop`、`while`、`for` 三種迴圈；Go 的 `for 條件 { }` 對應 `while`。
- `while` 裡的 `break` 不能帶值。
