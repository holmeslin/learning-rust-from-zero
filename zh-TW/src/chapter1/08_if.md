# `if` 與 `if` 是運算式

## 本集目標

用 `if`、`else if`、`else` 做判斷，並知道 Rust 的 `if` 可以直接產生一個值。

## 正文

### 基本的 `if`

寫法跟 Go 幾乎一樣：條件後面接大括號，大括號一定要有；`else if` 和 `else` 照常使用。

```rust
fn main() {
    let score = 75;
    if score >= 90 {
        println!("優秀");
    } else if score >= 60 {
        println!("及格");
    } else {
        println!("不及格");
    }
}
```

執行結果：

```text
及格
```

條件外面不用加小括號。加了也能編譯，但編譯器會警告你多餘，所以本書不加。條件也可以用上一集的 `&&`、`||` 組合。

### 條件必須是 `bool`

條件只能是 `bool`，不能拿整數當條件：

```rust,compile_fail=E0308
fn main() {
    let n = 1;
    if n {
        println!("yes");
    }
}
```

編譯錯誤：

```text
error[E0308]: mismatched types
 --> src/main.rs:3:8
  |
3 |     if n {
  |        ^ expected `bool`, found integer
```

這點 Go 也一樣，想判斷「是不是 0」就要老實寫 `n != 0`。

### `if` 是運算式

Rust 的 `if` 不只是流程控制，它本身會產生一個值，可以直接放在 `let` 右邊：

```rust
fn main() {
    let score = 75;
    let label = if score >= 60 { "及格" } else { "不及格" };
    println!("{label}");
}
```

執行結果：

```text
及格
```

大括號裡最後的 `"及格"` 和 `"不及格"` 後面沒有分號，沒有分號的那個值就是整個區塊的值。分號的細節第 2 章會解釋，現在只要記得：**想當成值的那個運算式，後面不加分號**。

用 `if` 當值有兩條規則：

- 一定要有 `else`，否則條件不成立時沒有值可給。
- 每個分支的值必須是同一種型別。

違反第二條的話：

```rust,compile_fail=E0308
fn main() {
    let n = 1;
    let x = if n > 0 { 1 } else { "no" };
    println!("{x}");
}
```

編譯錯誤：

```text
error[E0308]: `if` and `else` have incompatible types
 --> src/main.rs:3:35
  |
3 |     let x = if n > 0 { 1 } else { "no" };
  |                        -          ^^^^ expected integer, found `&str`
  |                        |
  |                        expected because of this
```

### 跟 Go 比一比

Go 的 `if` 只是陳述式，沒有值，也沒有 `? :` 三元運算子。想依條件決定一個變數的值，只能先宣告、再在分支裡賦值：

```go
label := "不及格"
if score >= 60 {
    label = "及格"
}
```

這個變數得是可以改的。Rust 用 `if` 運算式，`label` 建立之後就不用再改，`let` 就夠了，不必 `mut`。

另外，Go 的 `if` 可以在條件前面放一句初始化敘述，像 `if v := f(); v > 0 {`。Rust 沒有這個語法，先用 `let` 建立變數就好。

## 重點整理

- `if` 的條件不加小括號，大括號一定要有；`else if`、`else` 跟 Go 一樣。
- 條件必須是 `bool`。
- `if` 是運算式，可以寫成 `let 名稱 = if 條件 { 值 } else { 值 };`。
- 當成值使用時，一定要有 `else`，每個分支的型別要相同，值後面不加分號。
- Go 沒有 `if` 運算式也沒有三元運算子；Rust 沒有 `if` 的初始化敘述。
