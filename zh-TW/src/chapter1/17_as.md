# 型別轉換 `as`

## 本集目標

用 `as` 在數字型別之間轉換，並知道轉換時會發生什麼事。

## 正文

### `值 as 型別`

Rust 不會自動在數字型別之間轉換，要轉就自己寫 `as`。Go 寫 `float64(total)`，Rust 寫 `total as f64`：

```rust
fn main() {
    let total = 7;
    let count = 2;
    let average = total as f64 / count as f64;
    println!("平均是 {average}");
}
```

執行結果：

```text
平均是 3.5
```

`total` 和 `count` 是整數，先各自轉成 `f64`，再相除，才能得到帶小數的結果。如果直接寫 `total / count`，是整數相除，只會得到 `3`。

第 7 集那個 `i32` 跟 `i64` 不能比較的錯誤，也用 `as` 解決，把其中一邊轉成另一邊的型別就好：

```rust
fn main() {
    let a: i32 = 5;
    let b: i64 = 5;
    if a as i64 == b {
        println!("same");
    }
}
```

執行結果：

```text
same
```

### 浮點數轉整數：捨去小數

浮點數用 `as` 轉成整數，小數部分會直接丟掉（往 0 的方向），不是四捨五入：

```rust
fn main() {
    let price = 9.99;
    let whole = price as i32;
    println!("{whole}");
    let negative = -2.7;
    println!("{}", negative as i32);
}
```

執行結果：

```text
9
-2
```

### 大的整數轉小的：被截斷

整數轉成比較小的型別，放不下的部分會被直接截掉，只留下低位元的部分，而且**不會報錯**：

```rust
fn main() {
    let big: i32 = 300;
    let small = big as u8;
    println!("{small}");
}
```

執行結果：

```text
44
```

`u8` 只有 8 個位元，300 超過 255，只剩低 8 位元，變成 44。轉換的完整規則，附錄一 i 會再整理。

所以 `as` 用在「確定放得下」的地方最安全：小轉大、整數轉浮點數。轉成比較小的型別時，要自己確定值不會超出範圍。

## 重點整理

- `值 as 型別` 在數字型別之間轉換；Go 的 `float64(x)` 在 Rust 寫成 `x as f64`。
- 想用整數算出帶小數的結果，要先 `as f64`。
- 浮點數轉整數會捨去小數，不是四捨五入。
- 大的整數轉成小的型別會被截斷，不會報錯。
- 兩邊型別不同又要運算或比較時，用 `as` 把其中一邊轉成另一邊的型別。
