# struct 與方法

前面幾章的資料不是單一的數字，就是 tuple、陣列、`String`。想把「一筆訂單」「一個帳戶」這種有名字的資料放在一起，tuple 的 `.0`、`.1` 很快就會看不懂。這一章用 `struct` 定義自己的型別：每個欄位有名字、有型別；再用 `impl` 幫型別加上方法，`account.deposit(100)` 這樣的寫法就是從這裡來的。

`struct` 與方法在 Go 裡你用得很熟，這一章要注意 Rust 不一樣的地方：沒有零值，建立時每個欄位都要給；`let b = a;` 對 struct 是 move，不是複製；方法的第一個參數寫 `&self`、`&mut self` 還是 `self`，直接決定它是借用、修改還是拿走。第 3、4 章的所有權與借用，在這裡都會派上用場。
