# 閉包與迭代器

前面幾章反覆出現兩個先照抄的寫法：`for x in 陣列`、`for c in s.chars()`，還有好幾次「要用到閉包，第 11 章再學」的方法，例如 `sort_by`、`or_insert_with`。這一章把這些帳一次還清：閉包是什麼、會怎麼用到外面的變數；迭代器是什麼、`for` 背後在做什麼，以及 `map`、`filter`、`collect` 這一整排好用的方法。

Go 的程式習慣用 `for` 迴圈搭配累加變數，Rust 則偏好把「走訪、轉換、篩選、收集」串成一條。學會之後，第 7 章那些要寫迴圈的程式，很多都能縮成幾行。最後兩集回頭處理前面欠的債：`Option` 與 `Result` 的方法，以及 `entry` 的閉包版本。
