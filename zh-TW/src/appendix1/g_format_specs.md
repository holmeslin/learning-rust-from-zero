# 格式化進階

## 本集目標

在 `{}` 裡用格式說明符控制寬度、對齊、補字元、小數位數與進位，讓輸出對得整齊。

## 正文

大括號裡面，名字（或空白）後面接 `:`，再接格式說明符：`{name:>8}`、`{price:.2}`。`println!`、`format!` 都吃同樣的寫法。

### 寬度與對齊

`{x:8}` 的 8 是最小寬度，不夠就補空格。對齊用 `<`（靠左）、`^`（置中）、`>`（靠右）；補的字元可以換成別的，寫在對齊符號前面；數字前面寫 `0` 會補 0：

```rust
fn main() {
    let name = "tea";
    let price = 30;
    println!("[{name:8}]");
    println!("[{price:8}]");
    println!("[{name:>8}]");
    println!("[{price:<8}]");
    println!("[{price:*^8}]");
    println!("[{price:08}]");
}
```

執行結果：

```text
[tea     ]
[      30]
[     tea]
[30      ]
[***30***]
[00000030]
```

沒指定對齊時，字串靠左、數字靠右。

### 小數位數

`.2` 是小數位數。浮點數印到小數點後幾位，可以跟寬度一起用；字串用 `.3` 則是最多取幾個字元；`+` 一定印出正負號：

```rust
fn main() {
    let total = 1234.5678;
    let word = "abcdefg";
    println!("{total:.2}");
    println!("[{total:10.1}]");
    println!("[{word:.3}]");
    println!("{:+}", 5);
    println!("{:.1}", 0.25);
}
```

執行結果：

```text
1234.57
[    1234.6]
[abc]
+5
0.2
```

最後一行是 `0.2`，不是四捨五入的 `0.3`：剛好在中間時，Rust 取偶數那一邊。

寬度和位數也能放在變數裡，寫成 `名字$`：`{total:width$.digits$}` 會去找叫 `width`、`digits` 的變數。要印出大括號本身，寫成兩個：`{{`、`}}`。

### 進位

`x` 是十六進位，`X` 是大寫十六進位，`o` 是八進位，`b` 是二進位；前面加 `#` 會帶上 `0x`、`0b` 字首（就是附錄一 a 的寫法），`0` 加寬度可以補滿位數。`e` 是科學記號：

```rust
fn main() {
    let n = 255;
    println!("{n:x} {n:X} {n:o} {n:b}");
    println!("{n:#x} {n:#b}");
    println!("{:08b}", 5);
    println!("{:e}", 1234.5);
}
```

執行結果：

```text
ff FF 377 11111111
0xff 0b11111111
00000101
1.2345e3
```

### 兩個要注意的地方

寬度算的是**字元數**，不是畫面上的寬度。中文字在畫面上佔兩個英文字母的寬度，所以中英文混排、或字數不同時，看起來對不齊：

```rust
fn main() {
    for name in ["紅茶", "焦糖瑪奇朵"] {
        println!("[{name:<6}]");
    }
}
```

執行結果：

```text
[紅茶    ]
[焦糖瑪奇朵 ]
```

兩行都補到 6 個字元，但中文字比較寬，右括號就差了一格。這是字寬問題，Rust 沒有內建解法。

另一個是自己實作的 `Display`（第 8 章第 11 集）：用 `write!` 輸出的話，寬度會被忽略。要對齊，先 `.to_string()` 再格式化：

```rust
struct Money(u32);

impl std::fmt::Display for Money {
    fn fmt(&self, f: &mut std::fmt::Formatter) -> std::fmt::Result {
        write!(f, "${}", self.0)
    }
}

fn main() {
    let money = Money(30);
    let text = money.to_string();
    println!("[{money:>8}]");
    println!("[{text:>8}]");
}
```

執行結果：

```text
[$30]
[     $30]
```

### 跟 Go 比一比

Go 的 `Printf` 動詞可以直接對照：`%8d` 是 `{:8}`，`%-8d` 是 `{:<8}`，`%08.3f` 是 `{:08.3}`，`%.2f` 是 `{:.2}`，`%+d` 是 `{:+}`，`%x`、`%b` 是 `{:x}`、`{:b}`，`%*d` 是 `{:width$}`。

要小心的是字串的預設對齊：Go 的 `%8s` 靠右，Rust 的 `{:8}` 靠左，要靠右得寫 `{:>8}`。另外 Go 的 `%x` 也能印字串，Rust 的 `{:x}` 只能用在整數。

## 重點整理

- 格式說明符寫在 `:` 後面：`{名字:對齊 寬度 .位數 類型}`，例如 `{name:>8}`、`{price:.2}`、`{n:08b}`。
- `<`、`^`、`>` 控制對齊，前面可以放補字元；預設字串靠左、數字靠右。`0` 補 0，`+` 印正負號。`.2` 控制浮點數的小數位數，對字串則是最多取幾個字元。
- 進位用 `x`、`X`、`o`、`b`，加 `#` 帶字首，`e` 是科學記號；寬度與位數可以寫成 `width$`、`digits$`；大括號本身寫成 `{{`、`}}`。
- 寬度算字元數，中文會對不齊；自己實作的 `Display` 用 `write!` 時，寬度會被忽略，先 `.to_string()`。
- Go 的 `%8s` 靠右，Rust 的 `{:8}` 字串靠左。
