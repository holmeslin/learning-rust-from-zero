# 數字字面值

## 本集目標

認得數字字面值的各種寫法：用 `_` 分隔、`0x`／`0o`／`0b` 進位、型別字尾，以及浮點數的指數寫法。

## 正文

字面值（literal）是直接寫在程式裡的值，像 `42`、`2.5`。前面只用過最普通的寫法，其實數字字面值還有幾種變化。

### 用 `_` 分隔

數字很長時，可以在中間加 `_` 幫助閱讀。編譯器會直接忽略它，整數、浮點數都可以：

```rust
fn main() {
    let people = 1_000_000;
    let price = 1_234.567_8;
    println!("{people} {price}");
}
```

執行結果：

```text
1000000 1234.5678
```

慣例是整數每三位放一個 `_`。

### `0x`、`0o`、`0b`

前面加 `0x` 是十六進位，`0o` 是八進位，`0b` 是二進位。字母大小寫都可以（`0xff`、`0xFF`），也能搭配 `_`：

```rust
fn main() {
    println!("{}", 0xff);
    println!("{}", 0o17);
    println!("{}", 0b1010_1010);
}
```

執行結果：

```text
255
15
170
```

不管用哪一種進位寫，`{}` 印出來都是十進位。要印成十六進位或二進位，得用 `{:x}`、`{:b}` 這類寫法，附錄一 g 才教。

### 型別字尾

數字後面直接接型別名稱，就是指定它的型別。`10u8` 跟第 1 章第 3 集的 `let a: u8 = 10;` 是同一件事；字尾前面也可以放 `_`。字元前面加 `b`，例如 `b'A'`，值是 `u8` 的 65：

```rust
fn main() {
    let a = 10u8;
    let b = 2.5f32;
    let c = 0xff_u8;
    let letter = b'A';
    println!("{a} {b} {c} {letter}");
}
```

執行結果：

```text
10 2.5 255 65
```

沒寫字尾的時候，型別由上下文決定：`let a = 5;` 後面如果拿 `a` 跟一個 `u64` 相加，`a` 就是 `u64`。上下文決定不了，才是預設的 `i32`（整數）或 `f64`（浮點數），第 1 章第 15 集說過。

### 指數寫法

浮點數可以用 `e` 表示 10 的幾次方：`1e3` 是 1000，`2.5e-3` 是 0.0025。第 1 章第 15 集說浮點數要有小數點，更精確的說法是：有小數點、有 `e` 指數、或有 `f64`／`f32` 字尾，才是浮點數：

```rust
fn main() {
    println!("{}", 1e3);
    println!("{}", 2.5e-3);
    println!("{}", 5f64);
}
```

執行結果：

```text
1000
0.0025
5
```

### 字面值放不下，是編譯錯誤

沒有字尾、上下文又沒有指定型別時，整數是 `i32`。`3_000_000_000` 比 `i32::MAX` 還大，編譯器不會等到執行時才溢位，直接擋下：

```rust,compile_fail
fn main() {
    let n = 3_000_000_000;
    println!("{n}");
}
```

編譯錯誤：

```text
error: literal out of range for `i32`
 --> src/main.rs:2:13
  |
2 |     let n = 3_000_000_000;
  |             ^^^^^^^^^^^^^
  |
  = note: the literal `3_000_000_000` does not fit into the type `i32` whose range is `-2147483648..=2147483647`
  = help: consider using the type `u32` instead
  = note: `#[deny(overflowing_literals)]` on by default
```

這個錯誤沒有 `E` 開頭的錯誤碼，`note` 裡的 `overflowing_literals` 是這項檢查的名字，附錄一 j 會再看到。照 `help` 的建議，加上 `u32` 字尾就行。

### 跟 Go 比一比

Go 的 `010` 是八進位的 8（`fmt.Println(010)` 印出 `8`）。Rust 的 `010` 只是前面多了一個 0 的十進位 10，八進位要寫 `0o10`：

```rust,warn
fn main() {
    println!("{}", 010);
}
```

執行結果：

```text
10
```

這段程式能編譯，但 clippy 會警告 `this is a decimal constant`，提醒你是不是想寫 `0o10`。

另一個差別是 `1e3`。Go 的常數 `1e3` 可以直接放進整數變數（`var n int = 1e3`），Rust 的 `1e3` 一定是浮點數，`let n: i32 = 1e3;` 是 E0308。

## 重點整理

- `_` 可以放在數字中間幫助閱讀，編譯器會忽略它；整數每三位放一個。`0x`、`0o`、`0b` 是十六、八、二進位，`{}` 印出來一律是十進位。
- 型別字尾（`10u8`、`2.5f32`）指定字面值的型別；`b'A'` 是 `u8` 的 65。
- 沒有字尾時，型別由上下文決定，決定不了才用預設的 `i32` 或 `f64`；有小數點、`e` 指數或 `f64` 字尾，才是浮點數，`1e3` 是浮點數。
- 字面值超出型別範圍是編譯錯誤（`overflowing_literals`）。
- Go 的 `010` 是八進位，Rust 的 `010` 是十進位 10；八進位要寫 `0o10`。
