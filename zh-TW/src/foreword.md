# 從零開始學 Rust

你好！這份教學寫給**已經會寫 Go、但還沒碰過 Rust** 的人。迴圈、函式、struct 這些你早就懂了，所以我們不會從「什麼是變數」講起，而是把力氣花在 Rust 真正不一樣的地方。

## 為什麼是 Rust？

Rust 沒有 GC，卻能在編譯時期就擋下懸置參照、data race 這類記憶體錯誤。代價是你要學會跟編譯器溝通：所有權、借用、生命週期。這些觀念一開始會卡，但它們是 Rust 的核心，想通之後，很多在 Go 裡要靠測試或 `-race` 才抓得到的 bug，在 Rust 裡根本編譯不過。

本教學以 **Rust 1.99**、**edition 2024** 為準。

## 這份教學怎麼讀

- 每一「集」只教一個小概念，篇幅很短，請照順序讀。會 Go 的你可能覺得第 1、2 章很快，但請至少掃過每一集的「跟 Go 比一比」。
- 第 3、4 章講所有權與借用，這是全書最重要的兩章，請不要跳過。
- 第一部是語言基礎，只用標準函式庫；「附錄一」雖然叫附錄，也請讀完再進入第二部。
- 第二部介紹智慧指標、並行、async、進階語言功能與常用 crate，最後用 CLI 工具、Web 服務與 SQLite 做實戰。
- 書中範例都是完整的程式，可以直接按程式碼右上角的執行按鈕，在 [Rust Playground](https://play.rust-lang.org/) 上執行；沒有執行按鈕的範例（讀取鍵盤輸入、Playground 不支援的 crate）要複製到自己電腦上跑。
- 有些寫法會先請你「照抄」，背後的原理之後才會解釋。這是刻意的安排：先會用，再弄懂。

## 搭配 AI 學習

遇到看不懂的段落、想要練習題，或程式編譯不過時，可以請 AI 幫忙。下載本教學的原始檔壓縮檔：

> `rust-book-src.zip`：<https://holmeslin.github.io/learning-rust-from-zero/zh-TW/rust-book-src.zip>

把整個壓縮檔上傳給 AI，跟它說「請先閱讀壓縮檔裡的 `GUIDE.md` 再回答我」，並告訴它**你目前讀到第幾章第幾集**，再提出你的問題。這樣 AI 會配合你的進度回答，不會一下子丟出一堆你還沒學過的東西。建議使用能力較好的 AI 模型。
